Tasks

The company's shared to-do — write what needs doing and hit Add. Everything else is optional.

How this works

Assign one or more people, tag it by space, set a priority, break it into subtasks, and comment with @mentions. Add a quick checklist right under the description for simple steps that don't need their own assignee or due date. Set a cadence and completing it creates the next one automatically. Define custom fields (text, dropdown, date, money, checklist, and more) and every task can carry them. Group related work into a project with its own board and custom status columns — start one from a template, the same way ClickUp Folders and Lists are built. Build a form under Forms and submitting it creates and assigns a task automatically (shown with a 🗒️ so you can tell it came from a form), the same way Magic's ClickUp forms do today. Use the ⋮ menu on any card to duplicate a task or move it into a project (or back to the board).

Saves to your own browser for now — teammates on a different computer won't see it yet.
