Careers admin.

Manage the roles shown on the public careers page. Toggle a role off to hide it instantly from the public list, edit details, add new openings. Changes go live when the updated roles.json is committed to GitHub.

Edit on GitHub ↗

How publishing works

This hub is a static site, so the public page reads from one file: roles.json. Make your changes above, then either (1) hit Download roles.json and drag it into the GitHub repo, or (2) hit Copy JSON, open Edit on GitHub, paste over the file, and commit. The careers page updates in about a minute. Inactive roles stay saved here; they just never render publicly.
