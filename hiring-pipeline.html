What's improved vs. the ClickUp board

  • Grouped by phase (Not started / Active / Done) instead of one long row of 13 columns — easier to see where the funnel is thin.
  • Each Barrier links straight to its interview guide in the Hiring SOP — no separate tab hunting for what to evaluate.
  • Stat tiles up top for the numbers people actually ask for first: total candidates, active pipeline, offers out, and Barrier-1-to-offer conversion.
  • Same 13 stages as ClickUp today, so nothing gets lost in translation when we migrate the tracking in-house.

How to fill this in

  1. Open this file (hiring-pipeline.html) and find the column for the candidate's stage.
  2. Copy one .ccard block, replace the bracketed fields ([Candidate name], [Role], etc.) with the real details.
  3. Update the [ ] count next to the stage name, and the four stat tiles at the top.
  4. When a candidate moves stage, cut their card from one column and paste it into the next.
Before adding real candidate names: this repo is public on GitHub. Once committed, names stay in the git history even if later removed from the page. Confirm with Priscila how to handle this (real names, initials only, or keep it aggregate-only) before populating with live data.
